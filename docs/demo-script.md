# Demo Script (8 minutes)

1. **Landing (30s).** "AI may help express thoughts, never own them."
2. **Login (30s).** `demo@secondvoice.app / demo1234`. Point out language indicator.
3. **Speak (90s).** Big mic → say "I want meet doctor" → original shown untouched →
   suggestion side-by-side with highlighted diff + explanation. Badge the provider.
4. **User in control (60s).** Edit "the" → "my" → Confirm → Speak → Stop.
   Try Speak before confirm on a fresh item: blocked (409 UNCONFIRMED).
5. **Safety (60s).** Sample "I don't want to go." → system refuses to flip it;
   show abstention + clarification question.
6. **Learning (90s).** Correct "Arav" → "Aarav", approve. New session, same word →
   suggests "Aarav". Open Learning page: words learned, acceptance rate.
7. **Multilingual (60s).** Hinglish sentence → stays Hinglish. Explicit → English
   translation shown separately, confirmed before speaking.
8. **Evaluation (60s).** Learning → Compare: one sample, four pipelines
   (baseline / context-heavy / evidence-first / personalized).
9. **Close (30s).** Export data, delete controls, privacy note. No clinical claims.
